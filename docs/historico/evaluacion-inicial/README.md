# Evaluación inicial archivada

Estos informes corresponden al conjunto anterior, evaluado el 17 de octubre de 2026: 10 imágenes generales y 18 casos exploratorios con datos. Se conservan para mantener la trazabilidad; no representan el conjunto vigente de 20 imágenes de la línea A.

Las imágenes con datos se retiraron durante el cambio de conjunto. El 18 de octubre se recuperaron, con los mismos hashes, en [examples/limitations](../../../examples/limitations/README.md), para revisar límites sin ampliar el objetivo principal. Los informes guardan nombres, hashes, referencias, respuestas y puntuaciones originales. Se simplificó la presentación de los Markdown; los JSON originales se conservaron sin cambios. La evidencia de las 18 láminas se reutiliza en el informe complementario y no se suma a los resultados del conjunto principal de 20 imágenes.

- [Informe inicial de imágenes generales](evaluacion-principal.md).
- [Informe exploratorio inicial](evaluacion-exploratoria.md).
- [Rúbrica original en texto](rubrica-alt-text-original.txt), conservada sin modificar sus bytes para mantener el hash de los informes.

El [informe vigente](../../evaluacion-principal.md) utiliza exclusivamente el conjunto actual. Las gráficas, los diagramas y los esquemas con datos quedan fuera del objetivo principal y se estudian como casos complementarios.

La [evaluación complementaria vigente](../../evaluacion-limitaciones.md) reutiliza estas respuestas reales con su fecha original. No se presenta la recuperación de archivos como una nueva ejecución del servicio.
